# MAEX 11.26v2 程序性记忆测评

RoboMemArena seed 100，共 26 个任务。已获得 26/26 项官方评分。

高层规划使用 DeepSeek，视觉核验使用本地 Qwen3.8-27B，控制使用固定种子采样的 π0.5。8 个仿真工位并发，单局预算为 2,500 步和 900 秒。程序性记忆从本轮新建的 SQLite 空库启动，各局在启动时锁定当时的最新修订，结束时发布符合条件的回放案例。同一 seed 的不同任务可以共享符合条件的通用恢复经验。

RoboAgent 取当次原始对照表中的 baseline 列，按任务 ID 和 seed 配对。每格依次为官方 TSR、官方 CSR、仿真步数和运行秒数。差值为 MAEX 减 RoboAgent，前两项单位为百分点。运行时间含单任务启动、仿真、模型等待和程序案例写入，常驻模型的加载时间在外。两次实验的服务负载可能不同，时差反映完整运行设置。
