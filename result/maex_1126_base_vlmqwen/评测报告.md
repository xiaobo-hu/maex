# MAEX 本地 Qwen3.8 高层规划实验

RoboMemArena seed 100，共 26 个任务。已获得 26/26 项官方评分。

高层全局规划、局部前瞻和恢复使用本地 Qwen3.8-27B（8002，关闭 thinking）。临时入口使用 vLLM JSON Schema 约束规划回复，并交回 MAEX 原有的计划校验。视觉核验使用独立的同权重服务（8050），π0.5 使用同任务和种子的固定采样。8 个仿真工位并发，单局预算为 2,500 步和 900 秒。

RoboAgent 取当次原始对照表中的 baseline 列，按任务 ID 和 seed 配对。每格依次为官方 TSR、官方 CSR、仿真步数和运行秒数。差值为 MAEX 减 RoboAgent，前两项单位为百分点。运行时间含单任务启动、仿真和模型等待，常驻模型的加载时间在外。两次实验的服务负载可能不同，时差反映完整运行设置。

## 轨迹解读

- 任务 06、09、10、15、16 的初始计划均未通过 MAEX 校验，因而没有派发动作。失败集中在重复倾倒的序号不能按同一目标从 1 连续编号，部分回复还出现目的地字段不合法。这几项的瓶颈发生在高层规划阶段。
- 这 5 项贡献了全部净步数下降的 56.4%。在 MAEX 实际派发动作的 21 个任务上，配对平均步数为 1,712.2 对 2,065.5。双方都成功的 5 项平均为 1,004.8 对 1,286.6 步，194.6 对 197.2 秒。
